## Build Instructions
1. Clone repository.
2. Go to *Radovan-nRF52840IMU\IMUSensor\src\Motion_Sensor\pca10056\motion_sensor\ses.
3. Open motion_sensor.emProject in **Segger Embedded Studio**.
4. Select **Clean Solution** from Build tab.
5. Then select **Build Solution**.
6. Press Ctrl+T,L to burn the hex to MCU.

## Opentrack Software Instructions
1. Open Serial Tracker options.

![image](https://user-images.githubusercontent.com/106241042/205326793-d1ac097e-f26e-4435-8672-299cf8309350.png)
  
2. Select COM PORT.

![image](https://user-images.githubusercontent.com/106241042/205327339-85797ef5-99ba-4a9f-9e9d-d14a94b62c04.png)

4. Set the baudrate to 9600.
5. Click Start.
